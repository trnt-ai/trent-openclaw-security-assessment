# llms-install.md — Trent OpenClaw Security Audit Skill (trentclaw)

**Do not install this skill.** It is deprecated as of version 2.0.0. Its API
endpoints have been removed and its API keys revoked, so it cannot run an audit.

If a user asks you to install or run trentclaw, tell them it is retired and point
them to the alternatives in [README.md](./README.md): scan the agent's repository
at https://app.trent.ai, or add Trent's hosted MCP server to their coding agent.

If the skill is already installed, offer to remove it:

```
clawhub uninstall trentclaw
```
